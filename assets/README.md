# Profile visual assets

Everything here is generated from deterministic geometry and `data/profile.json`; no analytics, third-party image service,
external font, or runtime dependency is involved.

| Path | Source |
|---|---|
| `hero-dark.svg`, `hero-light.svg`, `hero-dark.gif` | `../scripts/generate-hero.mjs` (and `generate-hero-animation.sh` for the GIF) |
| `cards/`, `focus-strip-*`, `tech-strip-*` | `../scripts/generate-profile-assets.mjs` from `../data/profile.json` |
| `icons/` | vendored Simple Icons, see `ICONS-NOTICE.md` |
| `../README.md` | generated by `generate-profile-assets.mjs` (do not edit by hand) |

Change the content in `data/profile.json`, then:

```sh
node scripts/generate-profile-assets.mjs        # regenerate assets and README
node scripts/check-profile.mjs --render         # verify (the --render overflow check needs a chromium binary)
```

The README selects light or dark assets with GitHub-supported `prefers-color-scheme` sources in `<picture>` elements. Asset URLs are
absolute `raw.githubusercontent.com` URLs of this repository at `asset_ref` (`data/profile.json`); the hero stays on `main`.
Private projects appear as described cards with a PRIVATE pill and no link. Figures on cards are dated snapshots (`as_of`), not live data.
