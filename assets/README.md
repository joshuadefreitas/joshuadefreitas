# Profile visual assets

`hero-dark.svg` and `hero-light.svg` are generated by
[`../scripts/generate-hero.mjs`](../scripts/generate-hero.mjs). The geometry is
deliberately deterministic and self-contained: no analytics, third-party image
service, external font, or runtime dependency is involved.

Regenerate after changing the source:

```sh
node scripts/generate-hero.mjs
```

`hero-dark.gif` is a deliberately restrained, 48-frame packet animation built
from the same geometry. Regenerate it with the macOS-provided `sips` and
`ffmpeg`:

```sh
scripts/generate-hero-animation.sh
```

The profile README selects the matching asset using GitHub-supported
`prefers-color-scheme` sources in a `<picture>` element: the animated dark hero
for GitHub dark mode, and the static light hero for GitHub light mode.
