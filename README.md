# Joshua de Freitas

> Systems, security, data, and machine intelligence — built as inspectable, reproducible tools and studies.

I work across AI/ML, data systems, computational research, developer infrastructure, and security. I care about clear boundaries, evidence that survives review, and systems that can be understood all the way down.

## Selected public work

- **[trace-npm](https://github.com/joshuadefreitas/trace-npm)** — a Linux-first evidence tool for observing what an npm lifecycle script actually does: files touched, subprocesses spawned, and network endpoints contacted. It makes execution explicit and documents its safety limits.
- **[Neural Field Study](https://github.com/joshuadefreitas/neural-field-study)** — an executable, deterministic computational-systems study of excitation, inhibition, topology, and intervention in a synthetic neural field.
- **[Time-Series Forecasting Experiments](https://github.com/joshuadefreitas/time-series-experiments)** — an archived but maintained-for-reference collection of reproducible forecasting and simulation experiments.
- **[Forecasting Remittances](https://github.com/joshuadefreitas/Forecasting-Remittances)** — an archived research project on forecasting remittance flows.
